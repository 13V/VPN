# Velora typography

Velora uses **Newsreader roman** for display copy and **Manrope** for body text and controls. Headlines use one upright style. Line breaks, scale, and spacing establish hierarchy without decorative italic emphasis. Keep the serif for large headlines, section titles, and the concept card; keep small labels, navigation, and functional text in the sans face.

Production Type describes Newsreader as a variable typeface designed for on-screen reading. Its optical-size axis lets the browser select a suitable cut as headline size changes. The font is self-hosted, with a Latin subset of the upstream variable roman WOFF2 file at commit `cfcb4f7af0e52c25e8df2a2431814c8e5fe2e155`. The upstream project and its [SIL Open Font License](https://github.com/productiontype/Newsreader/blob/master/OFL.txt) are at [productiontype/Newsreader](https://github.com/productiontype/Newsreader); the bundled license is in `licenses/Newsreader-OFL.txt`.

The previous Instrument Serif italic file was removed. Manrope remains self-hosted for small UI text, with its licence in `licenses/Manrope-OFL.txt`.

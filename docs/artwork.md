# Website artwork

The landing page uses a custom generated glass sculpture in `public/connection-sculpture.jpg`. It replaces the original vector globe and decorative coin/chart illustrations. The image is decorative; it makes no representation about the supplier, network coverage or product performance.

Created with the built-in image-generation tool. The original PNG remains in the local Codex generated-images directory; a 262,408-byte JPEG is bundled in the repository for the website. No external asset requests are needed. The JPEG preserves the original composition and uses quality-90 encoding.

## Final generation prompt

Use case: stylized-concept. Asset type: premium VPN website hero artwork, no typography. Create an exquisite cinematic photoreal 3D product photograph of two monumental interconnected rounded glass loops forming an abstract open portal, sculpted from thick smoky forest-green and translucent pale jade optical glass. A very fine champagne-metal inner bevel catches the light. The loops float just above a natural warm limestone plinth, with beautiful realistic caustics, reflections, delicate surface texture, and soft contact shadows. Quiet, architectural, expensive, physically convincing. A single oversized circular form with a secondary interlocking loop, generous negative space, centered in a portrait 4:5 composition, entirety of sculpture visible. Background is a seamless warm cream #f5f3ed studio environment, subtly fading into sage in the shadows. Soft large window light from upper left, deep inky-green shadows, restrained warm highlights. Shot like a collectible design object for a luxury design magazine, 85mm lens, precise sharp edges, rich material depth. No globe, no map, no text, no logos, no icons, no padlocks, no shield, no interface, no cartoon, no neon, no floating UI cards, no watermarks. This is artwork for a calm refined website about shared connection.

## Design integration

Warm bone backgrounds, forest-green type, muted sage and restrained brass accents accompany the image. Georgia display headings and the existing local system sans-serif avoid third-party font requests. The image has an explicit aspect ratio and descriptive alternative text. The portal uses matching colors and typography, with readable functional controls and existing demo disclosures.

# Velora identity

Original vector artwork, 22 September 2026. The two angled paths form a split V: individual access supported by a shared connection. The lowercase lettering is drawn from SVG paths, with no font dependency. The identity board includes the primary signature, reversed signature, standalone mark and small-format icon.

- `public/velora-logo.svg`: forest signature on transparent background.
- `public/velora-logo-light.svg`: cream signature for dark backgrounds.
- `public/velora-mark.svg`: standalone forest symbol.
- `public/favicon.svg`: cream symbol on a rounded forest square.
- `design/velora-identity.svg` / `.png`: presentation board.

Primary forest: `#18372e`. Warm cream: `#f5f3ed`. Supporting sage: `#61735d`. Keep at least half the mark's width clear around a standalone signature. Use the icon rather than the full wordmark below 100px wide. Preserve the proportions and the gap between the two paths; avoid shadows, gradients or additional outlines in the logo.

The website header, footer, sample workspace and portal use this identity. Generic references to VPN technology remain as written. Naming and trademark clearance are outside this design work.

Validation: all 79 existing tests passed; Vercel static build completed; logo assets loaded in the local browser on both pages; 390px mobile layouts showed no horizontal overflow. The branding was approved and included in the 22 September 2026 production update.
